NAMBA FAMILY QUICK DEPLOY

1. npm install
2. Copy .env.example -> .env.local
3. Add Firebase web config.
4. Enable Firebase Authentication -> Email/Password.
5. Create Firestore.
6. Set FIREBASE_SERVICE_ACCOUNT_PATH and run: npm run seed
7. Copy Kannadhasan UID into ADMIN_UID.
8. Deploy Firestore rules.
9. In Vercel, add all VITE_FIREBASE_* variables.
10. In Vercel, add FAMILY_CODE, FAMILY_PASSWORD, ADMIN_CODE, ADMIN_PASSWORD, ADMIN_UID, FIREBASE_SERVICE_ACCOUNT_JSON.
11. npx vercel
12. Enable Firebase App Check + email enumeration protection before public launch.

SECURITY:
- Do not commit .env.local or service-account JSON.
- The example passwords were supplied by the project owner; rotate them before public use.
- Firebase web config is client-side by design; Firestore Security Rules protect the data.
